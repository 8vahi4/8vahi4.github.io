# ChatGPT用ポーズリファレンス画像作成ツール

ChatGPTの画像生成機能に添付するための、2D人体ポーズ参照画像と補助プロンプトを作成するローカルWebアプリです。

外部サーバー、アカウント、APIキー、外部ライブラリは使用しません。入力したポーズ情報が外部へ送信されることもありません。

## Windows 11での起動方法

### 方法1：そのまま開く（最も簡単）

1. このフォルダーの `index.html` をダブルクリックします。
2. 既定のWebブラウザでアプリが開きます。

主要機能はこの方法で利用できます。ブラウザの制限でコピー機能が動かない場合は、下記の方法2を使用してください。

### 方法2：ローカルWebサーバーで開く

Pythonがインストール済みの場合は、PowerShellでこのフォルダーを開き、次を実行します。

```powershell
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。終了するときはPowerShellで `Ctrl + C` を押してください。

## 操作方法

### ポーズを編集する

- キャンバス上の丸い関節点をマウスでドラッグします。
- 関節に接続された線は自動で追従します。
- 関節は編集領域の外まで移動できます。外へ出た部分はPNGには書き出されませんが、座標入力や「全体移動」で戻せます。
- 「拡大率」を変更すると、ポーズの形を保ったまま頭部の円を含む全身を拡大・縮小します。
- 初期状態の100%は、旧バージョンの初期スケルトンを130%にした大きさです。
- 「ポーズ初期化」で関節位置と拡大率を正面直立姿勢へ戻せます。追加・削除した手足の本数と、各区間の表示状態・前後関係は維持されます。
- 「全初期化」は、現在のポーズ、画像設定、見本画像、操作履歴などをページ初回表示時の状態へ戻します。確認画面が表示され、ポーズ1～3のセーブデータは削除されません。
- 「操作を戻す」「操作を進める」で、関節ドラッグ、全体移動、拡大・縮小、座標入力、初期化をアンドゥ・リドゥできます。
- テキストや数値の入力欄にフォーカスがない場合は、`Ctrl + Z`、`Ctrl + Y`（または `Ctrl + Shift + Z`）も利用できます。
- 左右はキャラクター自身から見た左右として扱います。

### 関節座標を確認・入力する

- 画面左の一覧に、すべての関節のX・Y座標が整数で表示されます。内部では、滑らかなドラッグや回転のために小数精度を維持します。
- 頭・首・胸・腰は全幅、肩・肘・手首・股関節・膝・足首は右と左を横並びで表示します。身体部位の色が付いた項目は白文字の黒縁取りで表示されます。
- 原点 `(0, 0)` は編集エリアの左上です。座標は出力画像のピクセル位置にも対応します。
- 数値を入力してフォーカスを外すか、Enterキーで確定すると関節位置へ反映されます。
- 編集領域外の座標も入力できます。安全のため、直接入力できる範囲は `-100000`～`100000` です。
- 関節座標の右上にある「×」で一覧を閉じられます。閉じると編集エリアが空いた幅まで広がり、ページ上部の「関節座標」ボタンで元に戻せます。
- 「全体移動」または「ポーズ回転」がONの間は、個別の座標入力が無効になります。
- 基本の関節だけの場合、座標一覧内にはスクロールバーを表示しません。手足を追加して項目が増えた場合は、座標一覧内をスクロールできます。画面の高さが不足する場合はページ全体をスクロールしてください。

### 左右連動・左右対称・全体移動・回転を使う

- 「左右連動」をONにすると、左右対応する関節へ同じX・Y移動量を適用します。
- 「左右対称」をONにすると、対応関節へX方向を反転した移動量と同じY方向の移動量を適用します。
- どちらのモードもドラッグと座標入力で同じ動作をし、同時にはONにできません。
- 「全体移動」をONにすると、キャンバスのドラッグですべての関節を同じ量だけ移動できます。
- 全体移動中は個別関節の連動よりも全体移動が優先され、ポーズ形状と各モードの設定は維持されます。
- 「左右反転」は、R/Lの意味・色・ラベルを保ったまま、身体中心Xを軸に見かけのポーズを左右反転します。例えば右腕だけを上げたポーズは、左腕だけを上げたポーズになります。
- 「ポーズ回転」をONにすると、Waistを固定したままキャンバスのドラッグまたは−180～180度の数値入力でポーズ全体を回転できます。ドラッグ開始から終了までを1操作としてアンドゥできます。
- 回転中は関節座標、全体移動、左右連動・左右対称、左右反転、左右入替、拡大率、見本画像の移動が無効になります。リセットまたはアンドゥ・リドゥを行うと回転モードは終了します。
- 「左右入替」は、関節の位置を動かさず、腕と脚の色・R/L・日本語名を交換します。「腕だけ」「脚だけ」では対象部分だけを交換します。
- 反転・入替操作は、1クリックを1操作としてアンドゥ・リドゥできます。

### ポーズをセーブ・ロードする

- 編集エリア左上の「ポーズをセーブ/ロード」で、現在の状態をポーズ1～3へ保存できます。セーブデータはブラウザ内に保存され、ページを閉じても保持されます。
- セーブデータは同じブラウザ・同じ起動URLで利用できます。ブラウザのサイトデータを削除した場合や起動URLを変更した場合に備え、必要なポーズはエクスポート文字列でも保管してください。
- 保存対象は、関節座標、手足構成、重なり順、前後関係、ラベル表示、拡大率、画像サイズ、背景色、画像へ含めるラベルの設定、ポーズ黒化です。
- 見本画像、操作モード、選択中の関節、アンドゥ・リドゥ履歴は保存されません。
- 保存済みのセーブボタンは色と印が変わります。保存済みスロットへの上書きとロード時には確認画面が表示されます。
- ロードすると現在の編集状況とアンドゥ・リドゥ履歴を破棄し、保存時の状態を復元します。現在表示している見本画像は削除されません。
- 「エクスポート」は、現在の状態を文字列として表示し、クリップボードへコピーします。
- エクスポート文字列を貼り付け欄へ入力して「インポート」を押すと、内容の検証と確認の後に状態を復元します。不正な文字列の場合は現在の状態を変更しません。

### 見本画像を下敷きにする

1. 右側の「見本画像」でPNG、JPEG、またはWebP画像を読み込みます。
2. 不透明度と拡大率を調整します。
3. 「画像を移動」をONにし、見本画像をドラッグで移動して位置を合わせます。

見本画像の編集モード中は関節やスケルトンは動きません。見本画像は表示していてもPNG出力には含まれません。非表示や削除を行ってもポーズは維持されます。

### 表示を設定する

- 身体部位の色は、頭部＝黄色、胴体＝灰色、右腕＝青色、左腕＝赤色、右脚＝緑色、左脚＝紫色に固定されています。頭部は不透明な黄色の円で表示されます。
- 「関節ラベルの表示/非表示」でラベルごとの表示を切り替えられます。「すべて表示」「すべて非表示」も利用できます。
- 通常の関節編集モードでは、関節ポイントをダブルクリックしてラベルの表示・非表示を切り替えられます。「全体移動」「ポーズ回転」または見本画像の「画像を移動」がONの間は無効です。
- 関節ラベルは、ラベル同士・関節点・骨格線との重なりが少なくなる位置へ自動配置されます。ドラッグ中は現在位置を優先して不要な切り替わりを抑えます。
- Head以外は、関節点の円が編集領域と重なっている間はラベル全体も領域内に配置し、円が完全に領域外へ出た場合はラベル全体も領域外へ配置します。
- 左右入替を行ってもラベルの配置場所は維持され、表示するR/Lだけが切り替わります。
- 「重なり順」では、上にある項目ほど画像上で手前に描画されます。ドラッグ操作はアンドゥ・リドゥでき、セーブ・ロードとエクスポート・インポートにも保存されます。
- 「手足の前後関係」で、各腕・脚を手前または奥に設定できます。奥の部位は破線かつ薄い色になります。
- Headラベルは、頭部の外周線より外側かつ編集領域内に全体を表示できる位置だけに配置します。条件を満たす位置がない場合や、頭部外周円が編集領域の外へ完全に出た場合は表示しません。

### 手足を追加・削除する

- 「手足の追加/削除」から右腕・左腕・右脚・左脚を追加できます。上限は元の1本を含め、各側4本です。
- 「手足の追加/削除」「重なり順」「手足の前後関係」は初期状態では折りたたまれています。
- 追加した手足には番号が付き、座標・ラベル・前後関係も個別に設定できます。
- 手足の状態は、番号順の腕をすべて表示した後に、番号順の脚を表示します。
- 「前腕」「上腕」「脛」「腿」で区間ごとの表示を切り替えられます。上腕または腿をOFFにすると、その先の区間もOFFになります。
- ×ボタンで手足1本を削除できます。肩・股関節は内部の接続位置として保持されますが、その側の手足が1本もない場合は関節点を画像に表示しません。
- 手足の追加・削除と区間表示の変更もアンドゥ・リドゥできます。

### 画像設定と保存

1. 画像サイズと背景色（白・黒・透明）を選びます。「任意」では幅・高さを64～4096pxの整数で指定できます。初期サイズは1024×1536です。
2. 「関節ラベルも含める」で、関節ラベルを画像に含めるか選びます。
3. 「ポーズ黒化」をONにすると、色分けをやめてポーズを黒一色で表示・保存します。編集画面の関節点内部は操作しやすいよう白のままですが、PNGでは黒く塗りつぶされます。
4. 「画像を保存」を押します。保存形式はPNGです。

ポーズ黒化中はスケルトンが見えなくなることを防ぐため、黒背景を選択できません。黒化をONにした時点で黒背景だった場合は、自動的に白背景へ変更されます。奥に設定した部位の破線と薄い表示は維持されます。

編集領域の縦横比は、選択した出力画像サイズに連動します。画面の横幅が不足する場合は、右側設定の配置を早い段階で変更せず、編集領域をアスペクト比のまま縮小します。画面上の表示サイズと実際の出力ピクセル数は別に管理され、左側に表示される関節座標がPNG内の位置に対応します。見本画像はPNGには含まれません。

編集領域とPNGでは同じラベル配置を使用します。編集領域外にある関節・骨格線・ラベルはキャンバス境界で切り取られます。

### ChatGPT用プロンプトを使う

- 手足の前後関係などの設定を変更すると補助プロンプトが更新されます。
- 線の状態は1つ以上の部位を「奥」にした場合だけ文章へ追加されます。
- ポーズ黒化中は【色の意味】と色による左右説明が削除されます。
- 保存画像に関節ラベルが1つも含まれない場合は、【文字ラベル】の説明が削除されます。
- 保存画像の範囲外へ完全に移動した腕・脚は、【色の意味】と【線の状態】の対象から除外されます。骨格線や関節マーカーの一部でも画像内にあれば対象に含まれます。
- R/Lラベルの例示には保存画像内に実際に含まれるラベルを使用し、該当するラベルがない場合はR/Lの説明行を省略します。
- 手足を追加しても本数に関する文章は追加されません。右腕・左腕・右脚・左脚のいずれかをすべて削除した場合や保存範囲外へ完全に移動した場合は、該当部位の色説明が削除されます。
- プロンプト欄は読み取り専用で、関連する設定変更に合わせて自動更新されます。
- 「コピー」で文章をクリップボードへコピーし、保存したPNGと一緒にChatGPTへ添付します。

## 注意事項

- このツールはChatGPTの画像生成モデルを内部制御するものではありません。
- ControlNetと同等の精密なポーズ制御を保証するものではありません。
- 出力画像とプロンプトは、ChatGPTが構図やポーズを解釈しやすくするための参考情報です。
- 初期バージョンは2D表現です。3Dの奥行き計算、骨の長さ固定、関節可動域の制限は行いません。
